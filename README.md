# About
Vintage Story Multiplayer Server Docker container. 

# How-to
`docker compose pull`: Update the server image.

`docker compose up -d`: Build and start server.

`docker compose down`: Stop server.

`docker compose ps`: Quick status of container

`docker compose logs -f`: View and follow logs.
